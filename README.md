# Experiment No. 9 – Development of REST API Using Flask

## Aim
To develop a REST API using Flask, integrate a trained Machine Learning model, create prediction endpoints, and test the API using Postman.

## Introduction
A REST API allows applications to communicate with each other. Flask is a Python web framework used to create APIs.

## Tools and Technologies Used
- Python
- Flask
- Machine Learning
- Postman
- GitHub

## Project Files
- `app.py` – Flask REST API application
- `train_model.py` – Machine Learning model training
- `model.pkl` – Trained ML model
- `deployment_workflow.txt` – Deployment workflow documentation

## Implementation Steps
1. Created and trained a Machine Learning model.
2. Saved the trained model as `model.pkl`.
3. Developed a REST API using Flask.
4. Integrated the trained model with the Flask application.
5. Created a prediction endpoint.
6. Tested the API using Postman.
7. Checked API response and prediction output.
8. Documented the deployment workflow.

## API Testing
The API was tested using Postman to check the prediction endpoint and response.

## Performance Analysis
- Response Time: Record the measured response time.
- Prediction Accuracy: Record the model's actual accuracy.

## Result
Successfully developed and tested a Flask REST API integrated with a trained Machine Learning model.

## Conclusion
The REST API was created successfully using Flask. The trained ML model was integrated and tested using Postman.
